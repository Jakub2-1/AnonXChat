# Sound Files

This directory contains audio files for AnonXChat sound effects:

- `message-send.mp3` - Played when user sends a message
- `partner-found.mp3` - Played when a chat partner is found  
- `chat-end.mp3` - Played when chat ends or partner leaves

## Format Requirements
- Format: MP3
- Duration: 0.1-0.5 seconds recommended
- Volume: Should be normalized to prevent harsh sounds

## Customization
Replace these files with your own sound effects while maintaining the same filenames.
